# Kill Em All Shooter Game

## Overview
Kill Em All is an exciting shooter game where players engage in intense battles against AI opponents. The objective is to eliminate all enemy pawns while ensuring the player's survival.

## Features
- **Single Player Mode**: Face off against AI-controlled enemies.
- **Game Over Logic**: The game ends when the player is killed or all enemies are eliminated.
- **Dynamic AI**: AI controllers that react to player actions and can be marked as dead.

## Getting Started

### Prerequisites
- Unreal Engine (version X.X or higher)
- C++ development environment set up

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/diptesh2082/ShooterGame.git
   ```
2. Open the project in Unreal Engine.
3. Build the project to ensure all dependencies are resolved.

### Gameplay Instructions
- Use the keyboard and mouse to control your character.
- Aim and shoot at enemy pawns to eliminate them.
- Survive as long as possible to win the game.

## Code Structure
The project consists of several key files and directories:
- **Source/**: Contains the main game logic, including player and AI interactions.
  - **KillEmAllGameMode.cpp**: Contains the main game logic.
  - **ShooterAiController.cpp**: Manages AI behavior and decision-making.
- **Config/**: Configuration files for the project.
- **Saved/**: Contains saved game data.
- **DerivedDataCache/**: Caches derived data for faster loading.
